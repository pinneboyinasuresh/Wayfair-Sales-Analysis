# Wayfair Sales Analysis

## About the Project
This project analyzes Wayfair sales data for 2024 and 2025 using Python and Pandas.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab

## Work Done
- Cleaned the datasets
- Analyzed yearly and monthly revenue
- Compared product categories
- Identified the top 10 products
- Calculated return and cancellation rates
- Calculated Average Order Value (AOV)
- Created 3 visualizations

## Key Findings
- Revenue increased by approximately 21.95% in 2025.
- Furniture generated the highest category revenue.
- Bath generated the lowest category revenue.
- Cotton Patio Chair was the top product by revenue.
- November had the highest revenue in both years.

## Conclusion
This project helped me practice data cleaning, data analysis, and data visualization using Python.
